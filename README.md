# 🛰️ RS-Talker · 遥感影像对话 Agent（L1）

上传一张遥感影像，直接问「图里有什么」，模型用中文告诉你地物构成、分布格局和判断依据。

这是 L1 阶段的最小可用版本：**只做图生文，不调用任何 GIS 库**。目标只有一个——验证视觉大模型到底能不能读懂遥感图，以及什么样的 Prompt 能让它读得准。

## 快速开始

```bash
# Windows：双击 run.bat
# macOS / Linux：
bash run.sh
```

首次运行会自动建虚拟环境、装依赖、生成 `.env`，然后用记事本打开让你填 Key。填完再跑一次即可。

手动方式：

```bash
pip install -r requirements.txt
cp .env.example .env      # 填入 MOONSHOT_API_KEY
python app.py             # 浏览器打开 http://127.0.0.1:7860
```

## 配置

全部配置在 `.env` 里，只需要改一个 Key：

| 变量 | 说明 |
| --- | --- |
| `LLM_PROVIDER` | 预设名，见下表 |
| `MOONSHOT_API_KEY` | Kimi 的 Key，在 platform.moonshot.cn 申请 |
| `LLM_MODEL` | 覆盖预设模型，如 `kimi-k2.6` |
| `IMAGE_MAX_EDGE` | 上传图最长边，超过自动缩小，默认 1536 |

内置预设（都走 OpenAI 兼容协议，换预设只需改 `LLM_PROVIDER`）：

| 预设 | 模型 | 备注 |
| --- | --- | --- |
| `kimi` | `kimi-k2.6` | 默认。支持图片，带推理过程 |
| `kimi-intl` | `kimi-k2.6` | 国际站 `api.moonshot.ai` |
| `qwen` | `qwen-vl-max` | 阿里百炼，中文遥感描述强 |
| `siliconflow` | `deepseek-ai/deepseek-vl2` | DeepSeek 官方 API 无视觉，需走第三方托管 |
| `openai` | `gpt-4o` | 需代理 |
| `ollama` | `qwen2.5vl:7b` | 纯本地，不联网 |

## Prompt 模板

界面的「Prompt 模板 / 生成参数」折叠面板里可以切换四种模式，模板全文在 [prompts.py](prompts.py)：

- **通用描述** —— 影像类型判断 + 主要地物 + 分布格局
- **地物清单** —— 结构化输出：类别 / 位置 / 占比 / 判断依据
- **精细判读** —— 按五个区域逐块扫描，标注变化痕迹与不可判读区
- **自由问答** —— 只回答问到的，不展开

四个模板共用一套 `RULES` 硬约束，专门压制遥感场景下最常见的幻觉：

1. 不知道就说不确定，禁止编造传感器型号、成像日期、地名、坐标
2. 分辨率 / 波段 / 比例尺未知时不许假设；没有比例尺就不给公里数和面积
3. 位置用画面方位（左上、中央、右下），尺度用相对比例
4. 地物用规范分类名，并说明判断依据
5. 严格区分「可见事实」与「合理推测」

**改 Prompt 是提效果最划算的一步**，改完重启即可，不用动代码。

## 实现要点

**图像压缩**：高分二号整景动辄上万像素，直接 base64 会撞上接口体积上限，费用也翻倍。上传后等比缩到 1536 长边、转 JPEG q88 再编码——视觉模型内部本来就要降采样，这一步基本不损失判读信息，但能把请求体积压到原来的百分之一。

**多轮图像裁剪**：每轮回传历史图像会迅速吃掉上下文和额度。代码只保留最近 2 轮用户提问里的图像，更早的替换成一句提示文字。

**流式输出**：token 一个个吐出来，长回答不用干等。

## 排错

**界面提示「还没有配置 API Key」** — `.env` 里 `MOONSHOT_API_KEY=` 后面是空的，或者整行被 `#` 注释掉了。不要给值加引号，也不要在 `=` 两边留空格。

**`invalid temperature: only 1 is allowed for this model`** — `kimi-k2.6` / `kimi-k2.7` 是推理模型，只接受 `temperature=1`。代码默认不传这个参数，所以正常情况不会遇到；一旦遇到，说明 `.env` 里设了 `LLM_TEMPERATURE`，删掉即可。

**模型返回空内容** — 推理模型会先输出一段 `reasoning_content`，再输出正文。如果自己调接口时把 `max_tokens` 设得太小（比如 120），额度会被思考过程吃光，正文就是空的。本项目不设 `max_tokens`，不受影响。

**Moved 到别的电脑 / 别人克隆了仓库** — `run.bat` 会自动从 `.env.example` 生成 `.env`，`.env` 本身在 `.gitignore` 里，不会被提交。

## 已知限制

- 无法给出精确面积、坐标、成像时间——这些需要影像元数据和 GIS 计算，属于后续阶段
- 单色 / 雷达影像的判读准确率明显低于真彩色光学影像，模型未必会主动承认这一点
- 缩放到 1536 长边后，小块地物的细节会丢失；需要看细节时请先自行裁切局部再上传
- 模型没有「尺度感」，对「几栋楼」「大概多大」这类回答天然不可靠，Prompt 已尽量约束但无法根治
